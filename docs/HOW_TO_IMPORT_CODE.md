# Как перенести код «Я рядом» в этот репозиторий

Этот репозиторий создан как **чистая точка** для полноценного приложения Telegram X + «Я рядом».

Исходный код с историей разработки находится в:

**https://github.com/stephanvoznyak-dot/telegram-x**

## Рекомендуемый способ

### Вариант 1 — Переименовать существующий форк (самый простой)

Если вы хотите сохранить всю историю коммитов:

1. В настройках репозитория `telegram-x` → Rename → `telegram-x-ya-ryadom` (если имя свободно)  
   **или** оставить текущее имя и использовать этот репозиторий как «чистый» публичный.

2. Обновить description и README.

### Вариант 2 — Перенести код в этот репозиторий

```bash
# 1. Клонировать существующий форк с подмодулями
git clone --recursive https://github.com/stephanvoznyak-dot/telegram-x.git tgx-source
cd tgx-source

# 2. Добавить этот репозиторий как remote
git remote add clean https://github.com/stephanvoznyak-dot/telegram-x-ya-ryadom.git

# 3. Запушить main (или нужную ветку)
git push clean main --force

# 4. (Опционально) запушить теги
git push clean --tags
```

После этого этот репозиторий станет полной копией с кодом «Я рядом».

### Вариант 3 — Только файлы «Я рядом» (лёгкий)

Если нужен минимальный diff поверх чистого upstream:

1. Клонировать официальный Telegram X.
2. Скопировать файлы из `telegram-x`:
   - `app/src/main/java/org/thunderdog/challegram/ui/YaRyadom*.java`
   - `app/src/main/res/values/ids_yaryadom.xml`
   - изменения в `DrawerController.java`
   - `docs/`
3. Закоммитить и запушить в этот репозиторий.

## Рекомендация

Для полноценного приложения лучше использовать **Вариант 2** — тогда сохраняется вся история разработки и все оптимизации, сделанные 22–23 октября 2026.
